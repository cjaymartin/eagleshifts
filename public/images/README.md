# Leaflet Marker Icons

This directory should contain the following files from the Leaflet package:
- marker-icon.png
- marker-shadow.png

You can obtain these files from the Leaflet package by:

1. Installing Leaflet:
```bash
npm install leaflet
```

2. Copying the files from the Leaflet package:
```bash
cp node_modules/leaflet/dist/images/marker-icon.png public/images/
cp node_modules/leaflet/dist/images/marker-shadow.png public/images/
```

These files are required for the map markers to display correctly in the Locations system.
